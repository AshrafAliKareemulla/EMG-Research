# Paper-2 experiment notebooks — parallel run guide

These notebooks drive the proven experiment suite in `../paper_experiments/`. They exist to
**bury every limitation** flagged in `../EXTERNAL_RESEARCH_REVIEW.md` with a tested method behind
every number. Each notebook is thin: a **ground-truth GATE cell** (synthetic, known-answer checks —
must pass) → the **real run** on the cached frames → a summary.

## Run order

1. **`00_SELFTEST_ALL.ipynb` — run this FIRST.** Runs every experiment's synthetic ground-truth
   checks (no dataset needed, ~1 min). Only trust the real runs if this is all-green. Equivalent to:
   ```bash
   python -m paper_experiments.selftest      # exit 0 iff all ground truth holds
   ```
   (Validated here: **48/48 module checks + X1 PASS**.)

2. **Everything else in parallel.** `X1_floor_effect_correct`, `X2 … X14`. They are independent:
   each **reads the existing 250 ms parquet cache read-only** and **writes its own `results/<tag>/`**
   with atomic writes, so launching them all at once cannot corrupt anything.

## Parallelism / CPU

Each notebook has a `JOBS` variable (default **2**). **Keep the sum of `JOBS` across the notebooks you
run simultaneously ≤ your physical core count** (e.g. 12 cores → run 6 notebooks at `JOBS=2`, or all
of them at `JOBS=1`). `A` (X1) and the frame-building steps are the only CPU-heavy parts; the rest are
light. Nothing here uses the GPU.
